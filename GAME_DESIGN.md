# Slowerr

A little tram. A town without an end. Take the scenic route.

V0 is a playable browser journey through Amberline, an original Mediterranean-inspired town: butter-yellow trams, terracotta roofs, sea-glass shutters, flowering trees, warm stone, and a turquoise canal. References guide mood and palette, not copied assets.

The tram starts rolling at a gentle pace. Set a target speed with the throttle; W / Up accelerates, S / Down brakes, Space pauses, C cycles follow/cinematic/cab cameras, H hides the interface. There is no failure state, timer, destination, or required task. A bell is optional and synthesized locally after a user gesture. Default journey seed: amberline. Seeds are shareable via the URL.

V0 includes one town biome with palette variations. Future districts, stations, canals, bridges, weather, and time of day extend the world descriptor and environment boundaries. A full hand-painted art pipeline is beyond this geometric prototype.
